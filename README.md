# ごはん日記

毎日の朝食・昼食・夕食・間食を記録する、iPhone向けの個人用アプリ。

- 公開URL: https://takashimatajiri4141-design.github.io/gohan-nikki/
- ホーム画面に追加すると、独立したアプリとして全画面で開く（Safariの共有ボタン →「ホーム画面に追加」）
- サインイン不要・オフラインでも動作

## 記録の保存先

記録は**端末のブラウザ内（localStorage）だけ**に保存される。サーバーには一切送信しない。

そのため次の場合は消える。ときどき「バックアップを保存」でJSONを書き出しておくこと。

- Safariのデータを削除した
- ホーム画面のアイコンを削除した
- 機種変更した

書き出したJSONは「バックアップから復元」で読み込める（同じ日付は読み込んだ内容で上書き）。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・ロジック・保存すべて） |
| `manifest.json` | ホーム画面に追加したときのアプリ定義 |
| `sw.js` | オフライン動作用のService Worker |
| `icon-*.png` | アプリアイコン |
| `_make_icons.py` | アイコン生成スクリプト（Pillow使用） |

## 更新のしかた

`index.html` を編集して `main` にpushすると、数分でGitHub Pagesに反映される。
`sw.js` のキャッシュ名（`CACHE`）を変えると、利用者側の古いキャッシュが確実に入れ替わる。
